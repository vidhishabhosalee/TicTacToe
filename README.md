# TicTacToe

Introduction

Tic Tac Toe is a simple two-player game developed using Python and executed through a Jupyter Notebook environment. The project provides an interactive graphical interface that allows two players to play the game on the same computer.

Objective

The objective of this project is to develop a simple and interactive Tic Tac Toe game while demonstrating the use of Python in a Jupyter Notebook environment.

Features

* Two-player gameplay
* Player 1 uses X
* Player 2 uses O
* Automatic winner detection
* Winning combination highlighting
* Draw detection
* Restart option
* Interactive graphical interface
* Turn indicator
* Result notification

Technologies Used

* Python 3
* Jupyter Notebook
* Tkinter

Requirements

The following software is required to run the project:

* Python 3.x
* Jupyter Notebook or JupyterLab
* Tkinter library

How to Run

1. Install Python 3.x on your system.
2. Install and launch Jupyter Notebook or JupyterLab.
3. Open the Tic Tac Toe project notebook.
4. Run the notebook cells in order.
5. The game window will open after running the required cells.
6. Player 1 starts the game with X.

How to Play

1. Player 1 places X on any empty cell.
2. Player 2 places O on an empty cell.
3. Players take turns until the game is completed.
4. A player wins by getting three of their symbols in a row.
5. The winning combination can be horizontal, vertical, or diagonal.
6. If all nine cells are filled without a winner, the match ends in a draw.
7. The Restart option can be used to begin a new match.

Game Interface

The application provides:

* A 3 × 3 game board
* Player turn information
* Player symbol information
* A Restart button
* Highlighting of the winning combination
* Notifications for a win or draw

Project Structure

The project is provided as a Jupyter Notebook file:

Tic_Tac_Toe.ipynb

The notebook contains the complete project and can be executed using Jupyter Notebook or JupyterLab.

Conclusion

This project demonstrates the development of a basic interactive game using Python and a graphical user interface. It provides a simple example of how Python can be used to create an interactive application within a Jupyter Notebook environment.
